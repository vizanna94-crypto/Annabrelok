# AnnaStory — лендинг брелоков-талисманов

Одностраничный лендинг для проекта AnnaStory: брелоки-талисманы ручной работы в подарочной упаковке с персональным предсказанием.

## 🔗 Ссылка на сайт

**Живая версия:** https://ВАШ_НИК.github.io/annastory-landing/

## 📄 О проекте

- **Продукт:** брелок-талисман ручной работы (250 ₽) и комплект «Талисман + Личный Разбор» (350 ₽).
- **Направления:** Любовь и гармония, Финансы и изобилие, Удача и новые возможности, Защита и спокойствие.
- **Особенность:** к каждому талисману прилагается интерактивная карточка с цифровым посланием и персональным предсказанием.
- **Приём заказов:** через личные сообщения ВКонтакте (https://vk.ru/annarazbor).

## 🛠 Стек

- Чистый HTML + CSS + минимум JavaScript (только для анимации появления блоков).
- Никаких фреймворков и сборщиков — файл открывается в любом браузере.
- Хостинг: GitHub Pages.

## 📂 Структура

- `index.html` — вся страница лендинга (разметка, стили, скрипт в одном файле).

## ✏️ Как редактировать

1. Откройте `index.html` в любом текстовом редакторе (VS Code, Notepad++, Sublime).
2. Внесите изменения.
3. Закоммитьте файл обратно в репозиторий (через сайт GitHub или через `git push`).
4. Через 1–2 минуты изменения появятся на живой версии сайта.
